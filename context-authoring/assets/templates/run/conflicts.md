# Conflicts: <scope>

The meta-skill fills every column up to "Suggested decision" and stops; people fill "Decision" and "Decided by". Skills that depend on no open row can be generated meanwhile.
Decisions: Variant | Align to A | Align to B | Fix code | Fix docs | Open. A contract break is never a Variant, and never gets a suggestion that is applied without a person reading it.

To decide quickly, reply with one line, for example: "accept all suggestions except 3 and 7; 3 is Align to B, 7 stays Open". Each accepted row gets "accepted suggestion" and the name of who accepted it.
